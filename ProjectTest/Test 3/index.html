9. Modules

             
Khái niệm: Modules (ES6 Modules) là cách để chia code JavaScript thành các file riêng biệt. Mỗi file là một module. Module giúp:

             
    
                 
  • Ngăn xung đột tên biến (mỗi module có scope riêng).
    • 
                 
  • Quản lý code tốt hơn, dễ bảo trì.
    • 
                 
  • Tái sử dụng code giữa các dự án.
    • 
             

             
Cách sử dụng:

             
Trong file JS muốn xuất (export) thứ gì đó (biến, hàm, class):

             
// file myUtils.js
export const PI = 3.14;
export function add(a, b) {
  return a + b;
}
export class MyClass { ... }
             

             
Trong file JS muốn nhập (import) thứ đó:

              
// file script.js
import { PI, add } from './myUtils.js';
import MyClass from './myModule.js'; // export default

console.log(PI); // 3.14
console.log(add(2, 3)); // 5
const instance = new MyClass();
              

              
Trong thẻ `<script>` của HTML, phải thêm `type="module"`:

              
<script src="script.js" type="module"></script>

              
Lưu ý: Cần chạy trang web này qua một local server (ví dụ: Live Server trong VS Code, hoặc Python SimpleHTTPServer) để `import` hoạt động do các hạn chế bảo mật của trình duyệt (CORS) khi chạy trực tiếp từ file (`file://`).
